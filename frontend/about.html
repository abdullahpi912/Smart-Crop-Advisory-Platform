About AgriSense

Empowering smallholder farmers and agronomy teams with machine learning insights for data-driven precision agriculture.

AgriSense is an end-to-end full-stack crop advisory platform developed as part of the Innolift Ventures Full Stack AI Developer Program by lead developer Abdullah P I.

Traditional farming heavily relies on inherited seasonal intuition or past crop choices, which can fail when local weather anomalies or soil nutrient depletion occur. AgriSense bridges this gap by pairing machine learning classification algorithms with an intuitive web interface.

By analyzing key field indicators — Nitrogen (N), Phosphorus (P), Potassium (K), Temperature, Humidity, Soil pH, and Rainfall — the platform accurately maps complex soil profiles to optimum high-yield crop choices.

Development Milestones

Project Roadmap & Progress

AgriSense is being delivered systematically across the Innolift Ventures Internship.

Phase 1: ML Model Training & Hyperparameter Tuning

Trained Decision Tree Classifier on the official Crop Recommendation Dataset. Achieved high classification accuracy tuned using Scikit-Learn's GridSearchCV.

Phase 2: Modern Earthy Frontend Redesign (HTML & CSS)

Created a modern, organic, highly responsive user interface featuring glassmorphic cards, pure-CSS interactive presets, and clean semantic layouts across 4 core pages.

Phase 3: Flask Backend API & MySQL Database Integration

Building RESTful endpoints to process form submissions, log farmer query history, and serve real-time model inference predictions.

Phase 4: Full System Integration & Cloud Deployment

Connecting frontend components with live model endpoints, adding real-time validation, and hosting the application on cloud infrastructure.
